# AutoPartes El Alto - Sistema de gestion de ventas e inventario

Proyecto Integrador II - Ingenieria de Sistemas, Universidad Privada Franz Tamayo.

Stack: Django REST Framework + React + PostgreSQL.

## Base de datos
- `database/schema.sql`  : modelo relacional (8 tablas, PK/FK)
- `database/seed.sql`    : datos de prueba
- `database/queries.sql` : consultas SELECT del proyecto

## Flujo de ramas
- `main`: version estable
- `develop`: integracion
- `feature/*`: trabajo por funcionalidad
